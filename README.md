# LinkSee｜声路·澳门

> 用游戏让无障碍被看见。

LinkSee 是一支由 5 名成员组成的青年团队，参赛项目为 **《声路·澳门》**。项目以澳门真实街景为蓝本，通过第一人称模拟盲人出行，让玩家在沉浸式体验中感知无障碍设施现存问题。

- 比赛：灣區AI未來青年創造營
- 方向：社会创新与城市无障碍游览
- 在线页面：[https://ranr21094-ai.github.io/LinkSee/](https://ranr21094-ai.github.io/LinkSee/)
- 联系方式：[winnyng0327@gmail.com](mailto:winnyng0327@gmail.com)

## 项目核心功能

### 1. 盲杖探索

点击或敲击模拟盲杖探测环境，不同地面材质提供差异化触觉与视觉反馈。

### 2. 感官导航

基于声音与视觉提示引导方向，模拟盲人依靠听觉与环境线索判断路径。

### 3. 多结局叙事

玩家的选择会导向不同结局，引发对无障碍议题的进一步思考与共鸣。

## 网页内容

团队介绍页采用单页编辑式视觉设计，主要包含四个内容区：

1. **参赛项目**：项目定位、服务群体、核心功能与体验流程。
2. **现实痛点**：澳门部分区域盲道及公众无障碍认知问题。
3. **核心亮点**：体验创新、模式创新与本土化创新。
4. **参赛目标**：赛事 72 小时目标及赛后长期发展计划。

页面同时提供：

- 五位成员的桌面悬停/键盘聚焦资料卡。
- 面向触屏设备的成员切换按钮和固定资料卡。
- 响应式桌面、平板和手机布局。
- 页面锚点导览、联系邮箱和本地内容管理入口。
- 澳门地图水印与暖白、朱红、钴蓝的编辑式视觉系统。

## 本地运行

需要安装 Node.js 18 或更高版本。

```bash
cd app
npm install
npm run dev
```

默认访问地址：<http://127.0.0.1:4173/>

本地管理页面：<http://127.0.0.1:4173/admin>

管理密码通过 `ADMIN_PASSWORD` 环境变量设置。请勿将真实密码、令牌或其他凭据提交到仓库。

## 构建与测试

```bash
cd app
npm run build
npm run test:sites
```

构建完成后，部署文件会生成在 `app/dist/`。测试会检查静态资源、单页路由回退、Sites 托管入口以及团队数据的一致性。

## 内容更新

团队成员和 01–04 项目内容统一维护在：

- `app/data/team.json`
- `app/public/team.json`

本地管理页面保存时会同步更新这两个文件。公开站点使用 `app/public/team.json`，因此内容修改后需要重新构建并发布。

本项目目前是参赛原型。相关体验与文字来自团队前期澳门无障碍议题调研，后续仍需与视障人士、无障碍服务机构及澳门在地伙伴共同测试和修正。
